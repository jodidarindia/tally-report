# v9.8.31 Build Notes — Multi-Company Safety

**What's inside**
- New `_preflight_or_skip()` on the sync worker. Before every cycle, the
  agent enumerates all loaded Tally companies via a new `ListOfCompanies`
  XML request and asks the FLOWRA server `POST /api/agent/preflight`.
  If two companies are open with no explicit intent, the cycle is
  SKIPPED — no ambiguous voucher pushes, no `LOAD COMPANY` attempts.
- `TallyCollectionClient.list_of_companies()` and `.get_current_company()`
  helpers so we can double-check `SVCURRENTCOMPANY` drift before / after
  each export.
- Version bumped everywhere:
  - `tally_sync_agent_v9.py`   → `9.8.31-multi-company-safe`
  - `flowra_gui.py`            → `APP_VERSION = "v9.8.31"`
  - `version_info.txt`         → `9.8.31.0` (both FileVersion + ProductVersion)

**Why we can't rebuild the .exe from this container**
PyInstaller must run on **Windows** to produce a Windows .exe. This
container is Linux + no Windows toolchain + no code-signing certificate,
so `build.bat` must be executed on your Windows build machine.

**On your Windows box** (usual build flow):
```bat
cd desktop-agent\build-kit
build.bat
:: → produces dist\FlowraTallyAgent.exe
:: rename → FlowraTallyAgent_v9.8.31.exe
:: sign  → signtool sign /a FlowraTallyAgent_v9.8.31.exe
```

2. `cp FlowraTallyAgent_v9.8.31.exe FlowraTallyAgent.exe` (the tenants
