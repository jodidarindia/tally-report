============================================
 FLOWRA Desktop Sync Agent v6 — QUICK START
 (File-Based — Zero Tally Freeze)
============================================

WHAT'S NEW IN v6:
  Instead of making HTTP requests to Tally (which freezes the UI),
  Tally now exports data to files on disk. The agent reads those files
  and syncs to your FLOWRA cloud dashboard.

  Result: ZERO freezing of Tally. You can work normally while sync runs.

============================================
 STEP 1: LOAD THE TDL IN TALLYPRIME
============================================

  1. Copy "flowra_export.tdl" to your TallyPrime folder
     (e.g., C:\TallyPrime\flowra_export.tdl)

  2. Open TallyPrime

  3. Go to: Gateway > F1 (Help) > TDL & Add-On > F4 (Manage Local TDLs)

  4. Add the full path: C:\TallyPrime\flowra_export.tdl
     Set it to "Yes" (Active)

  5. Press Ctrl+A to save, then restart TallyPrime

  6. You should now see "FLOWRA Auto Export" option on the Gateway menu
     (Press 'F' to trigger it)

============================================
 STEP 2: RUN THE FIRST EXPORT
============================================

  1. In TallyPrime Gateway, press 'F' (or click "FLOWRA Auto Export")

  2. Tally will silently export data to: C:\FlowraExport\
     You'll see these files:
       - stock_items.xml      (Inventory)
       - sales_vouchers.xml   (Sales)
       - receipt_vouchers.xml  (Receipts/Payments)
       - customers.xml        (Customer Ledgers)
       - _export_complete.txt  (Completion marker)

  3. This export runs in the background — Tally stays responsive!

============================================
 STEP 3: SETUP THE SYNC AGENT
============================================

  1. Install Python 3.8+ from https://python.org
     (Check "Add to PATH" during installation)

  2. Open Command Prompt in this folder

  3. Install dependencies:
     pip install requests xmltodict python-dotenv schedule watchdog websockets

  4. Copy .env.example to .env and edit:
     - BACKEND_URL = your FLOWRA cloud URL (e.g., https://your-app.com)
     - FINANCIAL_YEAR = your FY (e.g., 2025-26)
     - TALLY_EXPORT_DIR = C:\FlowraExport (default, change if needed)

  5. Run: python tally_sync_agent_v6.py
     Or double-click: run_agent.bat

============================================
 STEP 4: AUTOMATE EVERY 20 MINUTES
============================================

  The recommended setup runs exports automatically every 20 minutes.

  Windows Task Scheduler Setup:
    1. Press Win+R, type "taskschd.msc", Enter
    2. Click "Create Basic Task" on the right panel
    3. Name: "FLOWRA Auto Export"
    4. Trigger: Daily
       - Start time: when you start work (e.g., 9:00 AM)
       - Click "Repeat task every: 20 minutes" for "1 day"
    5. Action: Start a program
       - Browse to: schedule_export.bat (in this folder)
    6. Finish, then check "Open Properties dialog"
       - Check "Run whether user is logged on or not"
       - OK

  That's it! Every 20 minutes, Task Scheduler tells Tally to export,
  and the sync agent picks up the new files automatically.

  FILE BEHAVIOR:
    - Same files are OVERWRITTEN every export (not new files)
    - stock_items.xml, sales_vouchers.xml, etc. are updated in-place
    - The agent detects changes via file timestamp
    - Only changed data gets synced to cloud

  You can also manually export anytime by pressing 'F' in Tally Gateway.

============================================
 HOW IT WORKS
============================================

  [TallyPrime] --TDL Export--> [C:\FlowraExport\*.xml]
                                        |
  [Sync Agent] --reads files--> [Parse XML]
                                        |
  [Cloud Backend] <--HTTP POST-- [Sync data]
                                        |
  [Dashboard] <--WebSocket-- [Live updates]

  Zero HTTP requests to Tally = Zero freezing!

============================================
 TROUBLESHOOTING
============================================

  Q: "Export directory not found"
  A: Run the export from Tally first (press 'F' on Gateway).
     Or manually create C:\FlowraExport\

  Q: "No new data to sync"
  A: The agent only syncs when files change. Run export in Tally again.

  Q: "TDL not loading"
  A: Make sure the path in Manage Local TDLs is correct and set to "Yes".
     Restart TallyPrime after adding the TDL.

  Q: "Can I use both v5 (HTTP) and v6 (file-based)?"
  A: Yes! v5 (tally_sync_agent.py) still works if you prefer HTTP mode.
     v6 (tally_sync_agent_v6.py) is recommended for zero-freeze operation.
