============================================================
  FLOWRA Tally* Sync Agent v8.0 — Quick Start Guide
============================================================

REQUIREMENTS:
  - Python 3.9+
  - Tally* running on this machine (port 9000 default)
  - Internet connection to sync with FLOWRA cloud

INSTALL:
  pip install requests xmltodict python-dotenv schedule websockets cryptography

SETUP:
  1. Copy .env.example to .env
  2. Set your BACKEND_URL (get from FLOWRA admin)
  3. Run: python tally_sync_agent_v8.py

FIRST RUN:
  - Agent will ask for your FLOWRA email/password
  - Credentials are encrypted locally (AES-256 via Fernet)
  - Agent discovers all available FYs from Tally*
  - You select the STARTING FY to sync from
  - Sync runs automatically every 20 min

WHAT IT SYNCS:
  Phase 1:  Stock Items (inventory)
  Phase 2:  Sales Vouchers
  Phase 3:  Receipts & Payment Vouchers
  Phase 4:  Credit Notes
  Phase 5a: Journal Vouchers
  Phase 5b: Stock Journals
  Phase 6:  Purchase Vouchers
  Phase 7:  Debit Notes
  Phase 8:  Sundry Creditors
  Phase 9:  Contra Vouchers (bank transfers)
  Phase 10: Bank & Cash Ledger Balances
  Phase 11: Profit & Loss Data (income + expenses)
  Customer Ledgers with opening balances

COMMANDS:
  python tally_sync_agent_v8.py            # Normal run
  python tally_sync_agent_v8.py --logout   # Clear saved credentials

SECURITY:
  - Auth tokens encrypted with Fernet (AES-128-CBC)
  - Encryption key stored in hidden file (.flowra_key)
  - All data tagged with tenant_id + company_id
  - Token auto-expires after 23 hours
  - RAM optimized: chunked processing with gc.collect()

TROUBLESHOOTING:
  - "Tally not responding": Ensure Tally* is running, check TALLY_PORT
  - "Auth expired": Agent auto-refreshes, or run --logout to re-login
  - "No FYs found": Ensure a company is open in Tally*
============================================================
