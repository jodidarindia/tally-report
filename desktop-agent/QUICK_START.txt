==========================================
  FLOWRA TALLY SYNC AGENT v5 - QUICK START
  Lightweight Exports + Receipt/Payment Sync
==========================================

WHAT'S NEW IN v5:
- Uses standard Tally report exports (Day Book) instead of heavy TDL
- HTTP keep-alive session (faster, fewer connection issues)
- 120-second timeout with 2 retries per request
- Receipt/Payment voucher sync for accurate outstanding calculation
- Automatic retry with backoff on timeout

STEP 1: CONFIGURE TALLYPRIME
-----------------------------
1. Open TallyPrime
2. Press F12 (Configure)
3. Go to: Advanced Configuration > Connectivity
4. Enable: "Use Tally as Server" on port 9000
5. Save and restart Tally

STEP 2: INSTALL
---------------
pip install -r requirements.txt

STEP 3: CONFIGURE (.env file)
------------------------------
BACKEND_URL=https://your-flowra-app.com
FINANCIAL_YEAR=2025-26
TALLY_HOST=localhost
TALLY_PORT=9000
SYNC_INTERVAL_MINUTES=10
BATCH_SLEEP_SECONDS=3
REQUEST_TIMEOUT=120
MAX_RETRIES=2
ENABLE_WEBSOCKET=true
WEBSOCKET_PORT=8765
DEBUG_MODE=false

KEY SETTINGS:
- REQUEST_TIMEOUT: Seconds to wait per Tally request (default 120)
- MAX_RETRIES: Retries per request on timeout (default 2)
- BATCH_SLEEP_SECONDS: Pause between monthly fetches (default 3)

STEP 4: RUN
-----------
Double-click: run_agent.bat
  or
python tally_sync_agent.py

STEP 5: AUTO-START WITH TALLY
------------------------------
Double-click: start_with_tally.bat

HOW IT WORKS:
1. Connects to Tally ODBC server
2. Fetches stock items (single request)
3. Fetches ALL vouchers (Sales + Receipts + Payments) via Day Book
   report in monthly batches with sleep between each
4. Pushes data to FLOWRA cloud backend
5. Repeats every SYNC_INTERVAL_MINUTES

RECEIPT/PAYMENT SYNC:
- The Day Book report includes ALL voucher types
- Sales, Receipt, Payment, Contra, Journal vouchers are all captured
- Receipt data is used for accurate outstanding calculation
- Payment behavior analysis uses real receipt amounts

TROUBLESHOOTING:
1. Still timing out?
   -> Increase REQUEST_TIMEOUT to 180 or 300
   -> Increase BATCH_SLEEP_SECONDS to 10
   -> Restart TallyPrime before running the agent

2. Cannot connect?
   -> Check Tally server mode is enabled (F12 > Connectivity)
   -> Check port 9000 is not blocked

3. Debug mode: Set DEBUG_MODE=true in .env
   -> XML responses saved to debug_xml/ folder
