Trust & Security

Security at FLOWRA

Your books are the heart of your business. Here's exactly how we protect them — no marketing fluff, just the controls.

Encryption Everywhere

TLS 1.3 in transit, AES-256 at rest. Database volumes encrypted with separate KMS-managed keys.

India Data Residency

All servers in Mumbai (ap-south-1 / bom1). Your books never leave India unless you explicitly enable a feature that requires it.

Multi-Tenant Isolation

Every database query is scoped by tenant_id + company_id. Cross-customer data access is mathematically impossible.

Daily Encrypted Backups

Automatic daily snapshots retained 30 days. Weekly snapshots retained 12 months. Restore tested quarterly.

DPDP-Compliant

Built to India's Digital Personal Data Protection Act, 2023. Designated Grievance Officer with 7-day SLA.

Role-Based Access

Granular roles — admin, employee, salesman, dispatch, CA. Fine-grained permission per module.

1. Infrastructure

  • Application servers run on hardened Linux on DigitalOcean Mumbai (ap-south-1)
  • Database is MongoDB Atlas, M-tier dedicated cluster, replica-set with automatic failover
  • Network is locked to our private VPC; no direct database exposure to the public internet
  • Inbound traffic terminates at Cloudflare with WAF rules and rate limiting

2. Data protection

2.1 In transit

  • HSTS-enforced HTTPS, TLS 1.3 only, modern cipher suites
  • Certificate auto-rotation every 90 days via Let's Encrypt
  • The desktop sync agent uses the same TLS-pinned API endpoints

2.2 At rest

  • MongoDB Atlas storage encrypted with AES-256
  • Backup volumes encrypted with separate keys
  • Server disks encrypted with LUKS
  • Passwords hashed with bcrypt (cost 12) — no plaintext, no reversible storage

3. Authentication and access

  • Email + password with bcrypt-hashed credentials
  • Optional Google OAuth via Emergent-managed identity
  • JWT-based session tokens, signed with rotating HS512 keys
  • Session expiry, secure / HTTP-only cookies, SameSite=Lax
  • Brute-force protection: 5 failed attempts → exponential backoff
  • reCAPTCHA on the login page
  • Audit log of every admin action — exportable to CSV

4. Tenant isolation

FLOWRA is a multi-tenant SaaS, meaning many customers share the same servers. We isolate them at the data layer:

  • Every record carries tenant_id and company_id fields
  • Every query at every endpoint scopes by these fields — enforced both in middleware and at the route level
  • Compound indexes on these fields ensure performance doesn't tempt anyone to bypass them
  • Penetration tests and code review specifically check for tenant-leak bugs

5. The desktop sync agent

  • Open in source, written in Python, distributed as a standalone Windows .exe via official channels only
  • Reads Tally / Busy via the official XML / ODBC interfaces — never directly touches your data files
  • Authenticates with FLOWRA via your business token (revocable from the Tally Setup page)
  • All traffic over TLS 1.3 with TLS pinning to api.flowralive.in
  • Local cache encrypted; auto-purged on logout

6. Backups and disaster recovery

  • Continuous oplog backup with point-in-time recovery (PITR) granularity to 5 minutes
  • Daily encrypted snapshots retained 30 days
  • Weekly snapshots retained 12 months
  • Quarterly restore drills — we actually test it, we don't just claim it
  • RTO target: 1 hour. RPO target: 5 minutes

7. Operational security

  • Production access is limited to a small list of named engineers
  • All production changes go through code review + automated CI tests
  • Secrets stored in encrypted environment variables — never in source code
  • Dependency vulnerability scanning (npm audit + pip-audit) on every deploy
  • Centralized log aggregation with anomaly detection

8. Compliance

  • Digital Personal Data Protection Act, 2023 (DPDP) — fully compliant; Grievance Officer designated
  • Information Technology Act, 2000 — compliant data handling and grievance redressal
  • GST Reverse Charge Mechanism — invoice-compliant for all subscription billing
  • Working towards SOC 2 Type II in 2027

9. Responsible disclosure

Found a security issue? We want to hear about it. Please email security@flowralive.in with:

  • Description of the issue and impact
  • Steps to reproduce
  • Your contact details (if you'd like credit)

We commit to:

  • Acknowledge receipt within 48 hours
  • Provide a status update within 7 days
  • Not take legal action against good-faith researchers who follow this policy
  • Public credit (if you want it) on a Hall of Fame page once the fix ships

10. Status and uptime

Live status, incident history, and post-mortems are published at status.flowralive.in. We commit to 99.5% monthly uptime and credit customers for any breach.
